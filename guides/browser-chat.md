# Guide: browser chat only

For people who use **ChatGPT / Claude.ai / Gemini / similar** in the browser.  
No MCP, no `AGENTS.md`, no `/compact`, no CLI formatters.

**Core (why + figures):** [NOTES.md](../NOTES.md) · **Map:** [MAP.md](./MAP.md) · **Prompts:** [EXAMPLE-PROMPTS.md](../EXAMPLE-PROMPTS.md) (link sections; do not paste full fences here).

## Do this week (browser)

1. **New chat per unrelated task** — same as core P2.
2. **Short always-on instructions** — Project / custom instructions stay thin (P4).
3. **Pick the cheap model first** — frontier only when the ask is hard (P3).
4. **Paste less** — failing error slice, not the whole log (P7/P8).
5. **Ask for short answers** — bullets / STE100 / “no preamble” (P9).
6. **Check usage in the product UI** — don’t retype “how many tokens?” every turn (see NOTES Meter for CLI meters; browser = vendor usage page).

Use the [MAP](./MAP.md). Browser column only. One-liners:
