# Pattern map — browser chat vs CLI agents

**Rule:** Patterns, quotes, and % live once in core ([NOTES.md](../NOTES.md), [SOURCES.md](../SOURCES.md), [EXAMPLE-PROMPTS.md](../EXAMPLE-PROMPTS.md)).  
Guides only say **what to click / type in that UI**. If a figure appears twice, delete it from the guide and link here.

| ID | Core pattern (NOTES) | Browser chat action | CLI / coding-agent action |
| --- | --- | --- | --- |
| P1 | [MCP / tool hygiene](../NOTES.md#top-patterns-by-savings-impact) | N/A (no MCP). Disable unused **GPTs / apps / connectors** in the product settings. | Disable unused MCP servers; short schemas; Tool Search / defer load. `alwaysLoad: false` per MCP server defers all its tools. Hosts with huge catalogues: per-turn top-N + pin recently-used; fail open. MCP authors: search/describe/call discovery above ~100 tools. Default MCP description/instruction cap is 4,096 characters — still trim; do not treat the raise as free. On Tool Search: update to 2.1.302+ (cache-miss fix). Repeat repos: prune tools unused over several sessions (NOTES P1, TokenEconomizer). |
| P2 | [Fresh session / clear](../NOTES.md#top-patterns-by-savings-impact) | **New chat** when the task changes. Do not stack unrelated asks in one thread. | `/clear` or new session between unrelated tasks. Optional: write handoff file → `/clear` → `@handoff` (TinyFish pattern). Option: fresh session + transcript-recall tool instead of handoff/compact for ‘trap knowledge’; measure. Measured: [Kensei study](../NOTES.md#measured-study-12-claude-code-tips-945-runs-kensei-2026). Pro/Max: on the resume warning, prefer a new conversation (NOTES P2). |
| P3 | [Cheap-model routing](../NOTES.md#top-patterns-by-savings-impact) | Use the product **model picker**: cheap/fast for triage; frontier only for hard writing/code. Use extended-thinking / max toggles only when needed. | Pin Explore/leaf to Haiku (etc.); cold-boundary route; no mid-warm `/model`. Set effort deliberately per task; reserve max for hard steps. Haiku 5.5 on API billing: `/autocompact 100k` to stay in the ≤100K tier. Bounded route/classify steps: OpenAI Decisions API (NOTES P3). Per-task router example: Copilot Fusion in the AA index (NOTES P3). Compare leaf models on tokens per finished task, e.g. Particle-1 (NOTES P3). Default subagents to a cheaper model (NOTES P3, Uber). |
| P4 | [Lean standing instructions](../NOTES.md#top-patterns-by-savings-impact) | Keep **Custom instructions / Project instructions** short. Put task detail in the message, not always-on. | Thin `AGENTS.md` / `CLAUDE.md`; skills on demand. Manual-only skills: `disable-model-invocation: true` so descriptions stay out of startup context. |
| P5 | [Prompt-cache hygiene](../NOTES.md#top-patterns-by-savings-impact) | Keep long fixed instructions at the **top** of Project/custom text; don’t reshuffle them every turn. Self-hosted Open WebUI: run 0.12.4+ so tool order survives restarts (NOTES P5). | Stable system+tools prefix; don’t shuffle tools mid-session. OpenAI API / Codex builders: explicit breakpoint after stable prefix; change effort by appended update; check misses with cache diagnostics. Sonnet 5.5 cache reads $0.10 per million tokens (vendor, 7 Oct). Codex: provider now reuses context across subagents and caches longer (vendor, 16 Oct) — keep subagent prefixes stable. Gateways: same `x-session-id` per conversation. Keep history append-only; prune in batches (NOTES P5). Put volatile parts (env, memory body, timestamps) after the history (NOTES P5). Check that the first request of each session reads the cache; split shared prompt from env (NOTES P5, Cloudflare). API/cloud: `promptCacheTtl` 1h main, `subagentPromptCacheTtl` 5m. Compare hosts on cached cost and measured hit rate; log cached share per feature (NOTES P5, DevOps Daily). OpenAI API: `"12h"` only on the breakpoint after the all-day prefix; keep the request default `"30m"` (NOTES P5). Codex logged-in: old threads now hit the cache, so no handoff just for expiry (NOTES P5). Claude Code: set model/effort/fast mode at the start; `/compact` before a break; run `/loop` in its own session (NOTES P5). Own agents on Claude: marker after fixed instructions, run data after it (NOTES P5). Codex: an effort switch mid-thread no longer breaks the cache (NOTES P5). Claude Code: cache keep-alive conflicts with idle compaction; pick one per session (NOTES P5). Claude Code 2.1.311+: heed the `/effort` cache-miss warning in plan mode (NOTES P5). OpenAI on Bedrock: keep the tool catalog fixed; use `allowed_tools` / `additional_tools` (NOTES P5, AWS). Own agents: cache bugs are silent; alert on cached-token share and re-check model-name cache gates (NOTES P5, Silent and Costly). Load named skills only on the turn that calls them (NOTES P5, fx). |
| P6 | [Context compaction](../NOTES.md#top-patterns-by-savings-impact) | No `/compact`. Start a **new chat** and paste a short keep-list (decisions, errors, files). | `/compact` ~60% util with an explicit keep-list. Also: `/autocompact <window>` or earlier compact; if last turns went wrong prefer `/rewind` before `/compact`. On Bedrock/Vertex/Foundry/gateway, 1M is now default: `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` or `/autocompact 200k` (saved per model). Option: fresh session + transcript-recall tool instead of handoff/compact for ‘trap knowledge’; measure. Subagents: `autoCompactWindow` in frontmatter / `--agents` to compact earlier than the parent. API Haiku: `/autocompact 100k` (see P3). Idle compaction: 200K+ sessions idle ~54 min auto-compact before the 1h cache expires. Keep it for cost. Turn it off (`/config` → Idle compaction, or `"idleCompaction": false`) for long debug sessions; threshold `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`. Update to 2.1.304+ if you set `CLAUDE_CODE_AUTO_COMPACT_WINDOW` with a `k` suffix (NOTES P6). OpenAI GPT-6.1 Terra API: compact before a request passes 272K input tokens (NOTES P6). Claude Code 2.1.311+: standard-context sessions compact past 200K instead of stopping (NOTES P6). 2.1.312+: subagent `autoCompactWindow` lowers the env window; unknown cloud model names get the short system prompt (NOTES P6). 2.1.314+: idle compaction also in VS Code / Desktop and on cloud hosts with the 1h cache (NOTES P6). |
| P7 | [Context pruning](../NOTES.md#top-patterns-by-savings-impact) | Don’t paste whole logs/PDFs. Paste **only the failing slice**. | Prune tool exhaust first; DCP / fast-jev-compaction when available. Prefer clean Markdown/text fetch over raw HTML/curl dumps; optional sandbox index tools (context-mode) when measured useful. Search tools: ask for passages/highlights, not full pages (NOTES P7, Exa). Prune right after a cache miss, in large batches (NOTES P7). Count turns and repair loops before adding output compression (NOTES P7, TurnCost). Own agents: give big-result tools a “save to file” flag; the model gets a path and reads slices with `jq` / `grep` (NOTES P7, Langfuse Halo; Notion harness). Warm cache on a short task: don’t clear old tool output; meter fresh input, not peak context (NOTES P7, Kivo). Self-hosted SGLang: drop old tool-output KV instead of summarizing (NOTES P7, AKV). Script steps the model already chose (NOTES P7, HarnessMM). Product example: Vercel Agent context rebuild (NOTES P7). Shrink tool output on entry (trim or offload); later clearing can lose facts (NOTES P7, Makarevich replay). Own harness: fuse edit + test, archive big output behind a handle, verify cheap log receipts, compact at plan-step ends (NOTES P7, SoL-Pi). Many tool calls in a loop: one script, read only its output (NOTES P7, Factory Droid). Budget-reminder hooks after set tool-call counts (NOTES P7, HarnessPro). |
| P8 | [Targeted exploration](../NOTES.md#top-patterns-by-savings-impact) | Attach **one file** or quote a short span. Ask for a path before a dump. | Narrow `@files`; `rg` / tgrep / graph MCP; stop early. Enforce output filters with a global `PreToolUse` hook, not an `AGENTS.md` line (NOTES P8). Per-folder summary first, full file on demand (NOTES P8, OpenViking). RAG / doc agents: rerank before the agent reads, and send only the relevant spans (NOTES P8, Cohere); parse PDFs to Markdown/tables before they enter context (NOTES P8, Nemotron). `@`-mention a file once; daily commands with quiet flags in CLAUDE.md (NOTES P8). DuckDB 2.0: leave agent mode on (it auto-detects agents); expect a smaller tool output, not a smaller bill (NOTES P8). Pass structured findings so the agent skips discovery (NOTES P8, Snyk). Big document sets: pick folder/file/page before reading (NOTES P8, Drex). Repeat review jobs: code picks files and rules; the model only judges (NOTES P8, Open Code Review). |
| P9 | [Short / STE100 output](../NOTES.md#top-patterns-by-savings-impact) | Ask for **bullets / STE100**. “No preamble.” | Output-style / Concise rules — [EXAMPLE-PROMPTS](../EXAMPLE-PROMPTS.md). On coding agents, terse style cuts only narration; see the JetBrains test (NOTES P9). |
| P-CU | [Computer-use hygiene](../NOTES.md#computer-use-token-hygiene) / [CUA-S1 §10](../TYPESAFE-JEV.md#10-computer-use--specialist-system-one-for-local-gui-decisions-cua-s1) / [Jev Ultrafast §11](../TYPESAFE-JEV.md#11-browser-use-jev-ultrafast--indexed-dom--jev-optarget) | Rare in pure chat. Prefer vendor “fill form” / connectors over pasting screenshots. | Frontier plans; S1/Jev scores local actions; structured DOM ≫ screenshots; skip filled fields. Live web: indexed element table + Jev op/target (jev-ultrafast). Browser CLIs: send only changes (`snapshot --delta`, `screenshot --if-changed`). Batch page steps into one script; return only the result (NOTES Computer-use, Tabbit CLI). |
| P-UI | [Generative UI / json-render](../NOTES.md#generative-ui-token-hygiene-json-render) | Rare in pure chat. If the product must emit UI, prefer a **small component catalog** over pasting HTML. | Prefer **catalog JSON** (Zod/schema) over freeform HTML/JSX/markdown UI dumps. For streamed UI, a terse line DSL can beat JSON patch streams (NOTES Generative UI, OpenUI Lang). A2UI agents: use the Express format; code compiles it to JSON (NOTES Generative UI, A2UI Express). |
| P-OW | [Open-weights / offline](../TYPESAFE-JEV.md#open-weights-alternative-laya) · [laya-mlx](../TYPESAFE-JEV.md#apple-silicon-laya-mlx) · [Nimble](../TYPESAFE-JEV.md#nimble) · [local SGLang scoring](../TYPESAFE-JEV.md#local-scoring-sglang) · [StartLux-Decision](../TYPESAFE-JEV.md#startlux-decision) · [decision-backend chooser](../TYPESAFE-JEV.md#alternatives-landscape-decision-backends) | N/A (local runtime, or a decision API the product already calls). | Apple Silicon Laya: `pip install laya-mlx`, then `laya-mlx predict`. Nimble (Mac MLX or NVIDIA BF16): [Nimble](../TYPESAFE-JEV.md#nimble). Stock open LLM via SGLang: [local scoring tutorial](../TYPESAFE-JEV.md#local-scoring-sglang). Open decision models (vLLM / llama.cpp / MLX; non-commercial weights): [StartLux-Decision](../TYPESAFE-JEV.md#startlux-decision). Other backends (hosted Jev, djev, OpenJev, SemIf): chooser in TYPESAFE-JEV. No scores on this row. |
| P10 | [Subagents / workers](../NOTES.md#top-patterns-by-savings-impact) | Rare in pure chat. Use a **second chat** for research; paste only the summary back. | Explore/Plan subagents; return summary only. Isolation ≠ cheaper (see Agent Teams). Claude Code forks reuse the parent cache but carry its full context; `CLAUDE_CODE_FORK_SUBAGENT=0` turns them off (NOTES P10). Multi-agent: share short findings, not full traces (NOTES P10, Muffin). Spawn only for 10+ files, 3+ independent parts or fresh-eyes review. Own agents: try one loop + skills + tool search before subagents; fold one at a time against an eval (NOTES P10). Claude Code: each working background agent pays a summary call about every 30 s; meter it by `query_source` in OpenTelemetry (NOTES Meter, agent_summary). |

[Case 12](../ORCH-CASES.md#case-12-astra-plans-sol-implements-brad-groux).
